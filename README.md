# 學詞吧

音樂劇歌詞本：把找到的歌詞貼進來收藏，邊讀邊學英文。
不會的字點一下，記下中文、KK 音標、備註；之後在任何一首歌看到同一個字，都會畫線，點一下就看得到筆記。
資料存在自己的 Google 試算表裡，手機優先，可以加到主畫面像 App 一樣開。

- **歌詞本** — 作品 → 歌曲 → 歌詞。有中文翻譯就逐行對照（可以先藏起來自己讀），字可以放大縮小
- **記字** — 點字記單字；「從這裡選片語」再點最後一個字記片語。單字畫實線、片語畫虛線。
  同一個字在每首歌可以另外寫「在這首歌的意思」
- **單字表** — 搜尋、學習中／已會、單字／片語、依作品篩選；點進去看出現在哪幾首歌的哪一行，點一下跳過去
- **複習** — 卡片：正面英文＋出處那行歌詞，翻面看中文和音標；選全部、某個作品或某首歌

標成「已經會了」的字，歌詞裡不再畫線、也不出現在複習，但還在單字表，可以恢復。
外觀有淺色、深色、跟隨系統、粉紫，也可以**上傳自己的照片當背景**（只存在手機裡，不上傳）。

規格看 [需求規格.md](需求規格.md)。

## 第一次設定（三步）

### 1. 建一份 Google 試算表

隨便開一份新的試算表，名字自己取。分頁會在第一次連線時自動建好（作品、歌曲、單字、歌曲裡的意思）。

### 2. 部署後端

1. 在那份試算表裡：**擴充功能 → Apps Script**
2. 把 [google-apps-script/Code.gs](google-apps-script/Code.gs) 整份貼上
3. **把最上面的 `SECRET` 改成自己的一組密語**
4. 存檔 → **部署 → 新增部署作業 → 網頁應用程式**
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
5. 複製產生的網址（結尾是 `/exec`）

> 之後更新了 `Code.gs`，要**重新部署**（部署 → 管理部署作業 → 編輯 → 版本選「新版本」）。
> 設定頁最下面會顯示前端與後端版本。
>
> ⚠️ 改好密語的版本只貼在自己的 Apps Script 編輯器，**不要**貼回 GitHub。

### 3. 在 App 裡填進去

開啟 App → 右上角齒輪 → 貼上網址和**同一組**密語 → 儲存並測試。
右上角出現「已同步」就成功了。沒連線也能用，資料會先存在手機，連上之後自動補送。

手機上用 Safari 開，分享 → 加入主畫面。

## 開發

```bash
python3 scripts/serve.py 8791          # 本機伺服器，不走快取
node scripts/test-lyrics.js            # 斷字、比對、逐行對照的規則測試（不用瀏覽器）
PW_CORE=<playwright-core 路徑> node scripts/screenshot.js     # 走流程＋截圖＋抓 console 錯誤，結果在 shots/index.html
PW_CORE=<playwright-core 路徑> node scripts/test-layout.js    # 主題 × 頁面 × 寬度的版面掃描
node scripts/make-icons.js             # 重新產生圖示
```

改了 `www/` 裡的檔案，記得把 `www/sw.js` 的 `VERSION` +1。
測試資料一律虛構（[scripts/seed-demo.js](scripts/seed-demo.js) 的歌詞是自己編的），不要放真實歌詞或自己的單字筆記。
